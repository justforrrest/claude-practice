# claude-practice

순수 HTML/CSS/JavaScript로 만든 정적 웹 페이지 모음입니다.

## 프로젝트 구조

| 파일 | 설명 |
|------|------|
| `calculator.html` | Linear 디자인 스타일의 계산기 |
| `schedule.html` | 일정 관리 페이지 |

## 실행 방법

빌드 도구 없이 브라우저에서 파일을 바로 열면 됩니다.

```powershell
# 파일 직접 열기
Start-Process "calculator.html"

# 또는 로컬 서버 (Python 필요)
python -m http.server 8080
```

## 디자인 시스템

[Linear](https://linear.app) 디자인 언어를 참고하여 제작했습니다.

- 배경: `#0a0a0b`
- 강조색: `#7c3aed` (퍼플)
- 폰트: Inter (Google Fonts)
